# CAMPFIRE-TO-KINGDOM
焚き火から王国へ／CAMPFIRE TO KINGDOM（仮題）— 焚き火しか残っていない廃村を、木を切り岩を割って王国に育てるローポリ3Dの建国ゲーム（ブラウザで無料）

three.js で、キャラ・建物・木・岩・敵はすべて箱・円柱・球の組み合わせをコードで作っています（画像・3Dモデルのファイルなし）。

| --- | --- | --- |

| 2 | 第1章を完成（加工・お店・鍛冶屋・住民・土地購入・ぬし・強化・ミッション・タイトル・章クリア・留守の売上） | ✅ 試遊できる |
| 3 | 第2章 町（鉄の岩山・薬草の森・ゴブリンの砦、鉱山・宿屋・薬屋・市場、オオカミ・ゴブリン・ゴブリンの親分） | ✅ 試遊できる |
| 4 | 第3章 城下町（港の土地と海・骸骨の遺跡・金の山・巨人の谷、港と船・兵舎と兵士・大市場・城壁、トロル・骸骨の兵士・岩の巨人） | ✅ 試遊できる |

## 遊び方
- 画面のどこでもドラッグ（スマホは指を置いた所がスティック）／PCは WASD・矢印キー・マウスドラッグ
- 木や岩、敵に近づくと自動で切る・割る・戦う。拾った素材は背中に積み上がる
- 建設マスの上に立つと、背中の素材が流し込まれ、そろうと建物が直る
- 製材所・石工場：青いマスに素材を入れると、出口に板・石材が積もる（近づくと受け取る）
- お店：黄色いマスに立つと板・石材を並べる。客が買うとコインが積もり、近づくと受け取れる
- 鍛冶屋：台に立つと、モンスターの素材とコインで武器（さびた剣→石→鉄→ゴブリンの大なた→骨→金→炎→竜）と防具（旅人の服→ぷるぷる→毛皮→骨→金→竜）を作れる。斧・つるはしの強化もここ。作った装備は見た目も変わる
- 主人公のレベル：モンスターを倒す・建物を建てる・ミッション・住民の依頼で経験値。レベルが上がるとHPと攻撃力が上がる
- 右下の「強化」「住民」「図鑑」：積載量・移動速度の強化と施設・倉庫の強化（置ける量・速さ、Lvで見た目も変わる）／住民を雇う・仕事の強化／倒したモンスター・集めた素材・作った料理
- 住民の依頼：家の前に住民が立ち「!」でたのみごと（素材を持ってくる・モンスターを倒す・料理を作る）。かなえて話しかけるとコインと経験値
- 住民は建物・柵・岩をよけた道を探して歩く（`js/nav.js`）
- 運び手：加工場・鉱山の出口の品を倉庫へ運ぶ。倉庫に30個をこえてたまった品は、倉庫へ運ぶのと交互に市場・大市場・港へ運んで売る（倉庫が満杯のときは直接お店へ）。食堂の材料は最優先で厨房へ
- 冒険（右下）：宝箱を開ける・買う（コイン／星のかけら）。中身はコイン・素材・効果付きの武器（レア・エピック・レジェンド）。試練の塔（第1章クリア後）：階ごとに強くなる群れ、5階ごとにぬし。クリアでコイン・経験値・星のかけら、ぬしの階は星の宝箱。5階ごとの区切りから再挑戦できる。倒れても荷物は落とさない
- 鍛冶屋の「錬金」：同じ武器をもう1本使って +1（最大+5）、使った武器の効果を1つ受けつぐ。いらない武器は分解してコインに
- ぬしは倒して5分（遊んでいる時間）たつと復活し、また素材と宝箱を落とす
- 柵の門の外は狩り場（モンスターは狩り場にだけ出る）。狩り場の外側は柵ではなく岩や茂みの境目で、まわりの地面も狩り場の色。森・沼・土・遺跡・岩場・火山灰・竜の巣と、狩り場ごとに地面が違う。攻撃にはヒットストップ・会心の一撃（12%で2倍）・剣の軌跡・れんげき（続けて倒すと経験値が最大1.5倍）がある。モンスターは35%で素材を1個多く落とす。お店は食堂になり、モンスターの素材で料理を作って売る
- 朝・昼・夕焼け・夜がめぐる。BGM は設定で切りかえ
- 柵の外の土地はコインで買う。最後の土地「スライムの沼」のぬし（大スライム）を倒すと第1章クリア
- 第2章：鉄の岩山で鉄鉱石、オオカミから毛皮、薬草の森で薬草。鉱山は自動で鉄鉱石を掘る。宿屋は毛皮の毛布で旅人を泊めてコインをもらう。薬屋はゼリー＋薬草→薬（HPが大きく減ると自動で飲む）。市場はなんでも1.5倍で売れる。ゴブリンはコインを落とす。ゴブリンの砦の親分（突進と押しつぶし）を倒すと第2章クリア
- 第3章：港に商品を置くと、船が来てまとめて買っていく（1.3倍）。兵舎で雇った兵士は近くの敵を自動で倒す。大市場は2倍で売れる。城壁の門から北の森へ出入りできる。岩の巨人（岩を3つ投げる・押しつぶし・骸骨を呼ぶ）を倒すと第3章クリア
- 第4章：城は大きな建設マスで 土台→壁→塔→屋根 の順に建つ。竜のうろこはトカゲと子どものドラゴンから。ドラゴン（火を吹く・火の玉・押しつぶし・子どもを呼ぶ）を倒し、そのうろこで屋根をふくと城が完成し、戴冠式→スタッフロール→おしまい。その後も自由に遊べる
- 章をクリアすると「第N章へ」で次の章へ。前の章の土地・建物・住民はそのまま残り、土地が広がっていく
- いらない素材は、上の荷物の数（背中の積載量）をタップして選んで捨てる。背中がいっぱいのときにモンスターの素材を拾うと、木や石を自動で捨てて拾う。狩り場では木と岩は切らない。倉庫に預けた素材は建設・加工・お店・鍛冶屋で自動で使われる。右下の「倉庫」ボタンで中身を選んで売れる（1個・10個・全部。値段は素材の値段、木と石は1コイン）

## 確認用のURL
| URL の末尾 | 内容 |
| --- | --- |
| `?stress=150` | 住民とスライムを合わせて150体歩かせ、左下に fps・画質・描画回数を出す（重さの確認用） |
| `?fps=1` | fps などの表示だけ出す |
| `?q=low` / `?q=mid` / `?q=high` | 画質を固定（low = 影なし・解像度1倍、mid = 影なし、high = 影あり・自動調整なし） |
| `?debug=1` | プレイ動画用。タイトルで章（1〜4）を選ぶと、前の章まで終わった状態で、素材とコインを大量に持って章の最初から始まる（本物のセーブとは別に保存）。設定に「1時間留守にしたことにする」ボタンが出る。コンソールの `ctk.startEnding()` でエンディングだけ見られる |

画質は自動調整：スマホは最初から影なし、fps が 45 を下回り続けると影 → 解像度の順に下げます。

## 手元で動かす
ES モジュールを使うので、ファイルを直接開くのではなくサーバーから開く。
```
py -m http.server 8131
```
→ http://localhost:8131/

## 公開
更新を push する前に `py tools/version.py` を実行する（全ファイルの読み込みに版番号が付き、スマホに古いファイルが残らない）。

Settings → Pages → Source を **Deploy from a branch**、Branch を **main** / **(root)** にすると https://tanukibox.github.io/CAMPFIRE-TO-KINGDOM/ で遊べる。
