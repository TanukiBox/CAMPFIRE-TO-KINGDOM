# CAMPFIRE-TO-KINGDOM
焚き火から王国へ／CAMPFIRE TO KINGDOM（仮題）— 焚き火しか残っていない廃村を、木を切り岩を割って王国に育てるローポリ3Dの建国ゲーム（ブラウザで無料）

three.js で、キャラ・建物・木・岩・敵はすべて箱・円柱・球の組み合わせをコードで作っています（画像・3Dモデルのファイルなし）。

## 進み具合
| 区切り | 中身 | 状態 |
| --- | --- | --- |
| 1 | 移動・自動アクション（斧／つるはし／剣）・背中に積む・資源の復活・HPと倒れたとき・建設マスで修理 | ✅ 試遊できる |
| 2 | 第1章を完成（加工・お店・鍛冶屋・住民・土地購入・ぬし・強化・ミッション・タイトル・章クリア・留守の売上） | ✅ 試遊できる |
| 3 | 第2章 町（鉄の岩山・薬草の森・ゴブリンの砦、鉱山・宿屋・薬屋・市場、オオカミ・ゴブリン・ゴブリンの親分） | ✅ 試遊できる |
| 4 | 第3章 城下町（港の土地と海・骸骨の遺跡・金の山・巨人の谷、港と船・兵舎と兵士・大市場・城壁、トロル・骸骨の兵士・岩の巨人） | ✅ 試遊できる |
| 5 | 第4章 王国、エンディング | |

## 遊び方
- 画面のどこでもドラッグ（スマホは指を置いた所がスティック）／PCは WASD・矢印キー・マウスドラッグ
- 木や岩、敵に近づくと自動で切る・割る・戦う。拾った素材は背中に積み上がる
- 建設マスの上に立つと、背中の素材が流し込まれ、そろうと建物が直る
- 製材所・石工場：青いマスに素材を入れると、出口に板・石材が積もる（近づくと受け取る）
- お店：黄色いマスに立つと板・石材を並べる。客が買うとコインが積もり、近づくと受け取れる
- 鍛冶屋：台に立つと、素材（背中から）とコインで剣・斧・つるはしを強化できる
- 右下の「強化」「住民」：コインで積載量・移動速度・HPを強化／住民を雇う（木こり・鉱夫・運び手・店番）
- 柵の外の土地はコインで買う。最後の土地「スライムの沼」のぬし（大スライム）を倒すと第1章クリア
- 第2章：鉄の岩山で鉄鉱石、オオカミから毛皮、薬草の森で薬草。鉱山は自動で鉄鉱石を掘る。宿屋は毛皮の毛布で旅人を泊めてコインをもらう。薬屋はゼリー＋薬草→薬（HPが大きく減ると自動で飲む）。市場はなんでも1.5倍で売れる。ゴブリンはコインを落とす。ゴブリンの砦の親分（突進と押しつぶし）を倒すと第2章クリア
- 第3章：港に商品を置くと、船が来てまとめて買っていく（1.3倍）。兵舎で雇った兵士は近くの敵を自動で倒す。大市場は2倍で売れる。城壁の門から北の森へ出入りできる。岩の巨人（岩を3つ投げる・押しつぶし・骸骨を呼ぶ）を倒すと第3章クリア
- 章をクリアすると「第N章へ」で次の章へ。前の章の土地・建物・住民はそのまま残り、土地が広がっていく
- いらない素材は焚き火の横のマスでくべる。倉庫に預けた素材は建設・加工・お店・鍛冶屋で自動で使われる

## 確認用のURL
| URL の末尾 | 内容 |
| --- | --- |
| `?stress=150` | 住民とスライムを合わせて150体歩かせ、左下に fps・画質・描画回数を出す（重さの確認用） |
| `?fps=1` | fps などの表示だけ出す |
| `?q=low` / `?q=mid` / `?q=high` | 画質を固定（low = 影なし・解像度1倍、mid = 影なし、high = 影あり・自動調整なし） |
| `?debug=1` | プレイ動画用。タイトルで章を選ぶと、素材とコインを大量に持った状態で章の最初から始まる（本物のセーブとは別に保存）。設定に「1時間留守にしたことにする」ボタンが出る |

画質は自動調整：スマホは最初から影なし、fps が 45 を下回り続けると影 → 解像度の順に下げます。

## ファイル
| 場所 | 中身 |
| --- | --- |
| `js/data.js` | **数値と配置**。強化の値段、章ごとの素材・資源・敵・建物（必要な素材の数）・土地・ミッション・町の飾りはここを書きかえる（`CHAPTERS[章番号]`） |
| `js/state.js` | セーブされる進み具合（コイン・強化・雇った住民・買った土地など） |
| `js/stations.js` | 加工場・お店（客とコイン）・鍛冶屋の台 |
| `js/workers.js` | 住民（家で増え、雇うと働く） |
| `js/missions.js` | ミッション（いつも1つ表示・達成でコイン・段階解放） |
| `js/ui.js` | タイトル・強化・鍛冶屋・住民・章クリア・留守の売上の画面 |
| `js/coins.js` | コインの山と飛ぶコイン |
| `js/main.js` | 全体のつなぎ込み・毎フレームの処理・セーブ・設定 |
| `js/gfx.js` | レンダラー・カメラ・光・画質の自動調整・模型の焼き固め・丸い影 |
| `js/models.js` | 主人公・建物（壊れた／直った）・焚き火・建設マス・素材・木・岩・敵・住民の形 |
| `js/player.js` | 主人公（移動・道具の持ち替え・攻撃・HP） |
| `js/resources.js` | 木と岩（インスタンス描画、倒れる・復活） |
| `js/items.js` | 素材（落ちる・背中に積む・マスへ飛ぶ） |
| `js/enemies.js` / `js/rig.js` | 敵と、たくさん出るキャラを部品ごとにまとめて描く仕組み |
| `js/build.js` | 建設マスと修理・建設の演出 |
| `js/world.js` | 地面・柵・焚き火・草花・ぶつかり判定 |
| `js/hud.js` / `js/icons.js` | 画面の表示と、コードで描いた小さな絵 |
| `js/audio.js` | 効果音（コードで生成） |
| `js/i18n.js` | 日本語・英語 |
| `js/save.js` | 自動セーブ（localStorage） |
| `js/lib/three.module.min.js` | three.js r170（MIT, `js/lib/three-LICENSE`） |

## 手元で動かす
ES モジュールを使うので、ファイルを直接開くのではなくサーバーから開く。
```
py -m http.server 8131
```
→ http://localhost:8131/
