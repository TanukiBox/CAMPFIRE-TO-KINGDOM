# CAMPFIRE-TO-KINGDOM
焚き火から王国へ／CAMPFIRE TO KINGDOM（仮題）— 焚き火しか残っていない廃村を、木を切り岩を割って王国に育てるローポリ3Dの建国ゲーム（ブラウザで無料）

three.js で、キャラ・建物・木・岩・敵はすべて箱・円柱・球の組み合わせをコードで作っています（画像・3Dモデルのファイルなし）。

## 進み具合
| 区切り | 中身 | 状態 |
| --- | --- | --- |
| 1 | 移動・自動アクション（斧／つるはし／剣）・背中に積む・資源の復活・HPと倒れたとき・建設マスで修理 | ✅ 試遊できる |
| 2 | 第1章を完成（加工・お店・鍛冶屋・住民・土地購入・ぬし・強化・ミッション・タイトル等） | |
| 3〜5 | 第2章〜第4章、エンディング | |

## 遊び方
- 画面のどこでもドラッグ（スマホは指を置いた所がスティック）／PCは WASD・矢印キー・マウスドラッグ
- 木や岩、敵に近づくと自動で切る・割る・戦う。拾った素材は背中に積み上がる
- 建設マスの上に立つと、背中の素材が流し込まれ、そろうと建物が直る

## 確認用のURL
| URL の末尾 | 内容 |
| --- | --- |
| `?stress=150` | 住民とスライムを合わせて150体歩かせ、左下に fps・画質・描画回数を出す（重さの確認用） |
| `?fps=1` | fps などの表示だけ出す |
| `?q=low` / `?q=mid` / `?q=high` | 画質を固定（low = 影なし・解像度1倍、mid = 影なし、high = 影あり・自動調整なし） |
| `?debug=1` | 開発用（今は内部の値をコンソールから触れるだけ。章選び・素材大量スタートは区切り2で追加） |

画質は自動調整：スマホは最初から影なし、fps が 45 を下回り続けると影 → 解像度の順に下げます。

## ファイル
| 場所 | 中身 |
| --- | --- |
| `js/data.js` | **数値と配置**。章ごとの素材・資源・敵・建物（必要な素材の数）はここを書きかえる |
| `js/main.js` | 全体のつなぎ込み・毎フレームの処理・セーブ・設定 |
| `js/gfx.js` | レンダラー・カメラ・光・画質の自動調整・模型の焼き固め・丸い影 |
| `js/models.js` | 主人公・建物（壊れた／直った）・焚き火・建設マス・素材・木・岩・敵・住民の形 |
| `js/player.js` | 主人公（移動・道具の持ち替え・攻撃・HP） |
| `js/resources.js` | 木と岩（インスタンス描画、倒れる・復活） |
| `js/items.js` | 素材（落ちる・背中に積む・マスへ飛ぶ） |
| `js/enemies.js` / `js/rig.js` | 敵と、たくさん出るキャラを部品ごとにまとめて描く仕組み |
| `js/build.js` | 建設マスと修理・建設の演出 |
| `js/world.js` | 地面・柵・焚き火・草花・ぶつかり判定 |
| `js/hud.js` / `js/icons.js` | 画面の表示と、コードで描いた小さな絵 |
| `js/audio.js` | 効果音（コードで生成） |
| `js/i18n.js` | 日本語・英語 |
| `js/save.js` | 自動セーブ（localStorage） |
| `js/lib/three.module.min.js` | three.js r170（MIT, `js/lib/three-LICENSE`） |

## 手元で動かす
ES モジュールを使うので、ファイルを直接開くのではなくサーバーから開く。
```
py -m http.server 8131
```
→ http://localhost:8131/
